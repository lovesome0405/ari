# MARU 시연 안내

## 실행

Python 3.10 이상에서 저장소 루트 기준으로 실행합니다. 기본 카탈로그·저장 시연에는 API 키나 외부 유료 호출이 필요하지 않습니다.

```sh
python scripts/demo.py
```

브라우저에서 http://127.0.0.1:4173/ 를 엽니다. 종료는 터미널에서 Ctrl+C입니다. API는 기본 8080 포트를 사용합니다. 이 서버는 로컬 시연용이며 사용자별 인증을 갖춘 공개 운영 서버가 아닙니다.

## 3분 시연 순서

1. 0:00~0:25 — 외국인 방문객이 서울 공예·디자인 공간을 연결해 여행한다는 문제를 설명하고 언어를 선택합니다.
2. 0:25~1:10 — 추천에서 시간·관심사·이동 부담을 선택하고 결과를 비교합니다.
3. 1:10~1:55 — 코스 상세에서 방문 순서와 설명을 확인하고 지도 링크를 엽니다. 외부 지도는 연결이 필요합니다.
4. 1:55~2:25 — 코스를 저장하고 저장 화면에서 다시 확인합니다. 브라우저 저장과 서버 저장을 혼동하지 않도록 설명합니다.
5. 2:25~3:00 — 정적 시드 데이터와 규칙 기반 안내라는 현재 범위를 설명하고, 원본 데이터 검증·운영정보 갱신·사용성 평가 계획을 제시합니다.

## 발표 문안

마루는 외국인 방문객이 한국 공예와 디자인을 일정으로 경험하도록 돕는 모바일 웹입니다. 관심사와 체류 시간에 맞는 코스를 비교하고, 각 장소의 의미와 이동 순서를 확인한 뒤 저장할 수 있습니다. 현재는 서울의 대표 코스를 활용해 핵심 이용 흐름을 구현했습니다. 공개 화면과 기본 데이터는 오프라인 이용을 고려했고, 개인 API 응답은 공개 화면 캐시에 넣지 않습니다. 앞으로 실제 이용자 평가와 원본 데이터 검증을 통해 추천의 신뢰도와 방문 편의성을 확인하겠습니다.

## 검증 범위

오프라인 자동 테스트는 서비스워커 로직 테스트이며 실제 휴대폰 설치 테스트를 대체하지 않습니다. 최신 화면을 온라인으로 한 번 열고 서비스워커 설치가 완료된 뒤 오프라인 사용을 확인해야 합니다. 지도·실시간 API·외부 모델은 연결이 필요합니다. Python 서버는 AI 사진 편집을 제공하지 않습니다.
